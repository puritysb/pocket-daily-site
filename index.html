Free tools may already be enough

CrossPoint is free, open-source firmware. Its web transfer and free companion apps are options if you only need to send files or articles. Full Pocket Daily companion features require installing supported Pocket Daily firmware, so weigh that change against what already works for you.

How the firmware and app versions fit together

Regular updates

We base routine firmware updates on stable CrossPoint releases and test them with Pocket Daily’s changes.

Urgent fixes between releases

If Pocket Daily is affected by a security issue, data loss or recurring crashes, we may test and bring in the individual fix early. This is called a backport.

Before buying or installing

App reading needs no reader. Full companion features need supported ESP32-C3 X3/X4 hardware running Pocket Daily firmware. Ordinary CrossPoint is limited to discovery and explicit migration guidance in this app. Factory firmware cannot connect directly; X4 Classic/V2 and X4 Pro are different models. Confirm the exact model, installation eligibility and recovery method first.
