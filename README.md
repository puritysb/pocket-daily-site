# Pocket Daily website & support

Public introduction, Korean/English user guide, privacy policy, third-party
notices and introduction video for Pocket Daily.

- Website: https://puritysb.github.io/pocket-daily-site/
- 한국어: https://puritysb.github.io/pocket-daily-site/ko/
- Support: https://github.com/puritysb/pocket-daily-site/issues

The commercial app's source repository is private. This repository contains no
application source, signing materials, private hardware logs or app/firmware
distribution packages. Publishing the guide does not announce binary availability.

The introduction edits actual app demo screenshots with synthesized Korean
narration and bilingual captions. A separate19-second simulator recording shows
original article saving, reading and transfer preparation, with bilingual
captions and no audio. Neither video claims completed physical-reader delivery. The app and screenshots belong to Pocket Daily;
third-party components retain their respective license notices.

GitHub Pages serves main from the repository root. Generated files and their
reproducible source are maintained in the private app repository and exported
through an explicit customer-content allowlist. Do not import private docs here.
