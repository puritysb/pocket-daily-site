DEVELOPMENT BUILD · ACTUAL APP RECORDING

앱에서 화면 구성을 고르는 방법

실제 앱의 Choose a Home Layout 메뉴에서 Reading Focus, Book + Clock, Book + Agenda, Calendar를 차례로 선택합니다. 아래에는 같은 화면을 더 자세히 볼 수 있는 렌더링 영상도 있습니다.

미리 보고 선택하세요

  1. Reading Focus — Reading Focus에서 책 한 권을 중심으로 봅니다.
  2. Book + Clock — 같은 앱에서 Book + Clock을 골라 작은 시계를 더합니다.
  3. Book + Agenda — Book + Agenda는 책과 다음 일정을 함께 보여 줍니다.
  4. Calendar — Calendar는 별도로 선택합니다.

연결된 리더기에서는 지원되는 레이아웃 변경이 자동 저장됩니다. 데모는 기기를 변경하지 않습니다.

DEVELOPMENT PREVIEW · READER SCREEN RENDERS

읽는 책을 중심에 두는 화면

독서 화면과 시계·일정·날씨의 조합을 살펴보세요. 아래 영상은 실제 화면 그리기 코드의 결과를 편집한 것으로, 기기를 촬영하거나 버튼을 조작한 녹화가 아닙니다.

영상 내용을 글로 읽기
  1. 책 한 권을 크게 — 개발 빌드 미리보기. 선택한 책의 표지를 한 권씩 크게 보여 줍니다.
  2. 다음 책도 같은 자리에서 — 페이지 키로 선택한 책 사이를 이동합니다. 다른 화면으로 넘어가지 않습니다.
  3. 다른 화면은 직접 선택 — Views에서 Calendar를 직접 고릅니다. 화면 렌더링 예시입니다.
  4. 날짜를 골라 일정 확인 — Calendar에서 날짜별 일정을 확인합니다. 공개용 가상 일정입니다.
  5. 작은 시계를 더하면 — 다른 구성 예시: Book + Clock은 책 표지 위에 작은 시계를 배치합니다.
  6. 다음 일정은 간단하게 — 책과 다음 일정을 함께 봅니다. 일정은 공개용 가상 예시입니다.
  7. 필요한 날씨만 곁에 — 책과 함께 날씨를 표시합니다. 여기에 보이는 날씨는 예제 데이터입니다.
  8. 여러 책을 목록으로 — 선택한 책과 저장된 읽기 진행률을 목록에서 확인합니다.

눈이 편한 페이지로

페이지는 종이처럼 즉시 넘어갑니다. 종이, 흰색, 야간 페이지와 글꼴, 글자 크기, 여백을 내게 맞게 고르세요.

와이파이나 블루투스로 책과 글을 리더기에 바로 보내세요. 중간에 클라우드를 거치지 않습니다.
