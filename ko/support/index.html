리더기를 찾지 못해요.

리더기의 Sync → Same Wi-Fi가 열린 상태인지, Apple 기기와 같은 네트워크인지 확인하세요. 로컬 네트워크 권한과 게스트 Wi-Fi의 기기 간 통신 제한도 확인합니다. Find on Same Wi-Fi를 다시 선택하세요. 화면이 남아 있어도 기기는 절전 중일 수 있습니다.

Bluetooth 설정이 안 돼요.

리더기의 지원 펌웨어와 설정 모드, 앱의 Bluetooth 권한을 확인하세요. X3 자동 첫 설정과 X4의 수동 Sync 진입은 다릅니다. 먼저 Same Wi-Fi 경로로 연결할 수 있는지 확인하세요. 비밀번호나 페어링 코드를 문제 신고에 올리지 마세요.

전송 결과가 불확실하거나 멈췄어요.

같은 전송 작업을 다시 열고 원래 대상 리더기에 재연결해 결과를 확인하세요. 곧바로 같은 파일을 반복 전송하지 마세요. 리더기의 Library에서 파일을 확인하고, 실패가 반복되면 진단 정보를 검토해 신고하세요.

Failed to index 또는 SD 오류가 보여요.

원본 파일을 보관하고 다시 내려받은 DRM 없는 EPUB으로 확인하세요. SD 카드와 도서 파일은 컴퓨터에서 먼저 백업하세요. 카드 읽기 오류가 반복되면 포맷·초기화·캐시 전체 삭제보다 백업과 파일 확인을 먼저 하세요. 신고에는 오류 문구, 모델, 앱·펌웨어 버전, 재현 단계를 적습니다.

읽던 위치가 안 맞아요.

같은 책 파일인지 확인하세요. 변환·재저장한 파일은 다른 책으로 인식될 수 있습니다. Settings → Continue Reading, 같은 Apple 계정의 iCloud, 연결된 리더기의 공유 지원을 확인하세요. 기기별 글꼴과 페이지 크기가 다르면 페이지 번호는 달라질 수 있습니다.

설정을 바꿨는데 기기에 반영되지 않아요.

연결된 대상과 Home Screen·Sleep Screen 선택을 확인하고 해당 편집기의 Apply to Reader 결과를 확인하세요. 카드와 날씨·캘린더는 별도로 적용합니다. Demo 표시가 있으면 미리보기일 뿐 기기를 변경하지 않습니다.

업데이트가 없거나 설치가 안 돼요.

호환 공식 릴리스가 없으면 업데이트가 제공되지 않습니다. 전송 완료와 설치 완료는 다릅니다. 리더기에서 파일 확인과 Confirm이 필요합니다. 모델이나 복구 방법이 불명확하면 설치하지 마세요. CrossPoint 1.6.5의 큰 Wi-Fi 복사에는 알려진 제한이 있습니다.

리더기가 없는데 사용해도 되나요?

네. Library에서 책과 저장된 아티클을 읽을 수 있습니다. My Reader → Reader Options (•••) → Manage Reader → Try Demo로 연동 화면을 살펴볼 수 있습니다. 데모는 전송하거나 기기를 변경하지 않습니다.
